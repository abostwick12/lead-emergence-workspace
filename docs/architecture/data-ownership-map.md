# Data ownership map

Workspace owns personal projects, tasks, notes, meetings, decisions,
commitments, files, captures, job applications, memory, AI conversations,
briefings, knowledge feed data, integration metadata, and audit events.

Ministry retains students, volunteers, events, teams, attendance, curriculum,
ministry meetings, roles, ministry files, and all Camp/EMMA data. `auth.users`
is shared identity, not shared product data. Existing source meetings are not
migrated unless a future record-by-record review proves they are personal.
